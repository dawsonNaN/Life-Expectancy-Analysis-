# Starter folder

## Overview
This project explores the key factors associated with life expectancy across countries using a global dataset covering 193 countries from 2000 to 2015. The goal is to understand how socioeconomic conditions, healthcare indicators, and demographic factors relate to differences in life expectancy.




## File Structure

The repo is structured as:

-   `data/raw_data` contains the raw data as obtained from X.
-   `data/analysis_data` contains the cleaned dataset that was constructed.
-   `other` contains relevant  LLM chat interactions, and sketches.
-   `paper` contains the files used to generate the paper, including the R document，as well as the PDF of the paper.
